原型假设与口径说明

数据来源：数据库名、数据表名、需规编号、功能描述均取自 《国际科技信息中心项目_生命医学&工程细胞&低维材料_3系统进度监控.xlsx》—「生命医学主题库」，未改写原文。
界面参照：按参考平台 106.52.33.112:8090/#/zhongguanghe0915/data-assets/catalog（数据管理 → 元数据管理 → 元数据目录）复刻：左树「数据库 → 表」，点数据库右侧为「库表清单 / 信息概览」，点表右侧为「字段信息 / 示例数据 / 信息概览」。主色 #1459FA、选中底色 #E5EFFE 取自该站实测值。
字段信息：字段英文名 / 中文名 / 类型 / 非空 / 标准名称 / 数据分类 / 数据分级为按数据集类型生成的示例元数据，用于演示表级详情形态，需以真实库表结构替换。
示例数据：表格中的取值为程序生成的演示数据，姓名、身份证号、电话、住址等已做脱敏化处理，不代表真实患者数据。
剔除口径：四级功能点「眼病/慢病数据库」下，数据库名称含「知识图谱」的 5 组整组剔除，共 35 张表（数据集）；已核对保留项名称与描述中不含「知识图谱」字样。
占位模块：顶部「工作台 / 数据开发 / 数据共享」与左侧菜单其他项为参照站点的导航占位，点击仅给出提示。
